# ADR-001: Хүргэлтийн системд вэб суурилсан 3 түвшинт архитектур сонгох
**Төлөв:** Санал болгож сонгосон загвар (сургалтын ажил)

## Нөхцөл
Илгээгч, менежер, хүргэгч янз бүрийн төхөөрөмжөөр хандах; локер, төлбөр болон мэдэгдлийн гадаад системтэй интеграц хийх шаардлагатай.

## Шийдвэр
React танилцуулгын түвшин, Node.js REST API хэрэглээний түвшин, PostgreSQL өгөгдлийн түвшин.

## Харьцуулсан хувилбар
A Desktop + DB: 2.45; B Вэб 3 түвшин: 4.40 (сургалтын жишиг үнэлгээ).

## Үр дагавар
+ Утас/компьютерээс хандах, төвлөрсөн шинэчлэлт, сервисүүдийг салгах боломж.
- Интернет/серверээс хамааралтай, API хамгаалалт болон интеграцийн алдааг удирдах шаардлагатай.

## Эрсдэлийн арга хэмжээ
HTTPS, эрхийн шалгалт, аудит лог, нөөцлөлт, интеграцийн retry/timeout, локерын үйлдэлд баталгаажуулалт.
